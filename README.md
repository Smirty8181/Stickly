# Stickly

Настольные заметки-стикеры и небольшие списки дел для Windows. Каждый стикер — отдельное окно рабочего стола; заметки хранятся локально и автоматически восстанавливаются при следующем запуске.

## Возможности

- Отдельные перемещаемые окна стикеров с изменением размера и режимом «поверх окон».
- Главная панель и бумажные стикеры на HTML/CSS/JavaScript и pywebview; системный трей и глобальные сочетания остаются нативными.
- Автосохранение текста, цвета, положения, размера и размера шрифта в SQLite.
- Жёлтая, розовая, мятная, голубая, лавандовая, персиковая, серая и графитовая бумага, а также свой цвет.
- Ранее созданные кремовые и тёмные заметки и настройки цвета сохраняются.
- Локальный рукописный шрифт с поддержкой кириллицы, лёгкий бумажный рельеф и контрастный текст.
- Чек-листы внутри заметок, отметка выполнения, перестановка и удаление пунктов; общий список задач с фильтрами.
- Панель заметок с поиском, фильтром по цвету и сортировкой.
- Архив, корзина с восстановлением, подтверждение окончательного удаления и копирование заметок.
- Системный трей: открыть Stickly, создать, показать/скрыть стикеры, настройки и выход.
- Необязательные сочетания Alt+Ctrl+N, Alt+Ctrl+H и Alt+Ctrl+S.
- Необязательный автозапуск текущего пользователя Windows без прав администратора.
- Настройка поведения главного окна при закрытии: скрыть в трей или завершить программу.
- Экспорт заметок в JSON, проверяемый импорт без перезаписи текущих данных и резервная копия SQLite.
- База и журнал приложения хранятся в `%APPDATA%\Stickly`, а не в рабочей папке или каталоге EXE.

## Интерфейс

Главная панель оформлена в тёмной теме с фиолетовыми акцентами. Панель и каждый стикер отображаются в окнах pywebview на Edge WebView2. HTML, CSS, JavaScript и шрифт хранятся в проекте; для работы приложения не нужен доступ к интернету. WebView запущен в одном вспомогательном процессе и обменивается данными с приложением через локальный именованный канал. Это не блокирует цикл событий PySide6, который обслуживает трей и глобальные сочетания.

Примеры интерфейса находятся в [screenshots](./screenshots/): главная панель в режимах сетки и списка, пустое состояние, жёлтый и мятный стикеры, а также заметка с длинным текстом.

## Требования

- Windows 10 или Windows 11.
- Python 3.11 или новее для запуска из исходников.
- При запуске из собранного EXE отдельно устанавливать Python не нужно.
- Для окон стикеров нужен Microsoft Edge WebView2 Runtime (обычно предустановлен в Windows 10/11).

## Запуск из исходников

Откройте терминал в папке проекта:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Для свернутого запуска:

```powershell
python main.py --minimized
```

Второй запуск не создаёт второй экземпляр: команда передаётся уже работающей программе. Параметр `--create` создаёт стикер в работающем экземпляре.

## Проверки

```powershell
python -m unittest discover -s tests -v
```

Тесты используют временную базу и не меняют заметки пользователя.

## Сборка EXE

В активированном виртуальном окружении:

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --clean --noconfirm stickly.spec
```

Исполняемый файл появится в `dist\Stickly.exe`. Данные пользователя сохраняются отдельно в `%APPDATA%\Stickly`.

### Диагностика сборки

- Убедитесь, что сборка запускается из корневой папки проекта и активировано нужное виртуальное окружение.
- При ошибке недостающего модуля обновите зависимости командой `python -m pip install -r requirements.txt` и повторите сборку.
- Журнал установленной/собранной программы: `%APPDATA%\Stickly\stickly.log`.
- Если Windows не показывает значок в трее, проверьте настройки системных значков панели задач.
- Значок EXE и приложения создаётся из `assets\stickly-logo.ico`.

## Данные и восстановление

SQLite-база: `%APPDATA%\Stickly\stickly.sqlite3`. В приложении можно создать резервную копию базы и экспорт JSON. Импорт добавляет записи как новые, не заменяя существующие; некорректный файл отклоняется до изменения данных.

## Ограничения первой версии

- Интерфейс пока только на русском языке. Шрифт Neucha распространяется по SIL Open Font License; текст лицензии включён рядом с файлом шрифта.
- Главная панель пока использует тёмную тему; отдельное переключение темы не добавлено.
- Глобальные горячие клавиши зарегистрированы за Stickly на время работы приложения и могут быть заняты другой программой; при конфликте Stickly сообщит об этом.
- Автозапуск и глобальные горячие клавиши доступны только в Windows.
- Полупрозрачность регулируется средствами окна Windows; отдельный ползунок прозрачности пока не включён.
- Настройки поведения стикеров при запуске пока ограничены восстановлением тех окон, которые были открыты перед предыдущим выходом.
- Резервную копию SQLite можно восстановить после выхода из программы, заменив файл базы в `%APPDATA%\Stickly`; перед заменой сохраните текущую копию.
